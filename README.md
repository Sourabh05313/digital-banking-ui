# Digital Banking UI

A modern **digital banking customer segmentation UI** built with **React and Vite**. This is a frontend-only project focused on a clean, responsive banking interface for presenting prospective customer segments.

## ✨ Features

- Modern digital banking-inspired interface
- Customer segmentation cards
- Segments such as **Satisfied**, **Underserved**, and **Underbanked**
- Reusable React components
- Responsive frontend design
- Vite-powered development workflow
- Clean component-based structure

## 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- ESLint
